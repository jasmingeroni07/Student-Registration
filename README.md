# Student Management System

A simple Student Management System built using **HTML, CSS, and JavaScript**. This project allows users to add, edit, and delete student records through a clean and user-friendly interface.

## Features

- Add new student records
- Edit existing student information
- Delete student records
- Input student name and email
- Select a student program
- Display student records in a table
- Save student records in the browser using Local Storage
- Cancel editing when needed

## Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and layout
- JavaScript – Functionality and student record management
- Local Storage – Saving student records in the browser

## Available Programs

- BSIS

- BSED
- BEED

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all files are in the same folder.
4. Open `index.html` in your web browser.
5. Start adding student records.

## Purpose

This project was created to practice and demonstrate basic web development skills using HTML, CSS, and JavaScript. It also provides a simple way to manage student information.
